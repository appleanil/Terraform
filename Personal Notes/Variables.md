| Type    | Description (single line)                                     | Example (single line)                              |
|---------|---------------------------------------------------------------|----------------------------------------------------|
| String  | A sequence of characters or text.                             | `"devops"`, `"us-east-1"`, `"ap-south-1"`          |
| Number  | A numeric value, either integer or decimal.                   | `500`, `1000`, `10`                                |
| Boolean | A value that is either true or false.                          | `true`, `false`                                    |
| List    | An ordered collection of values of the same type.             | `["dev", "test", "prod"]`, `["t3.micro", "t2.small"]` |
| Map     | A collection of key-value pairs with values of the same type. | `{dev = "small", prod = "large"}`                  |
| Object  | A collection of named attributes that can have different types.| `{name = "dev", size = 2}`                          |
| Tuple   | An ordered collection of elements that can have different types.| `["dev", 500, true]`                              |
